# HPre 1.0.15 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement video startup metrics breakdown and pipeline optimizations, ensure adaptive aspect-ratio fit across device screens, prevent loading flicker, update versioning to 1.0.15, and verify release readiness.

**Architecture:** Refine fine-grained telemetry in `VideoOpenMetrics`, enhance `PlayerSurface` with `RESIZE_MODE_FIT` and safe inset padding in Compose overlays, eliminate duplicate/unnecessary media prepare calls, and maintain shared ViewModel/PlayerController integrity across device rotation and fullscreen toggling.

**Tech Stack:** Kotlin, Jetpack Compose, Media3 (ExoPlayer), AndroidX Navigation, Coroutines / StateFlow.

**Spec:** `docs/superpowers/specs/2026-08-31-hpre-1.0.15-design.md`

## Global Constraints
- Target version: versionName = "1.0.15", versionCode = 16.
- Maintain existing A -> B -> C -> D -> Back -> Home navigation behavior.
- Ensure strict ABR defaults without forced track resets.
- Zero breaking changes to `PlayerController` and `PlaybackUiCoordinator` public APIs.
