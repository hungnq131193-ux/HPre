# HPre 1.0.11 Startup and Comments Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce median video tap-to-first-frame time, ship the approved lightweight comments layout, and publish a signed HPre 1.0.11 APK through a reviewed GitHub pull request.

**Architecture:** Keep the existing Watch, NewPipe bundle, and Media3 boundaries. Restore the bundle cache capacity, gate only the separate comments endpoint on current-player readiness with a bounded fallback, and render comment metadata with existing Compose, Coil, Android formatting, and lazy-list facilities.

**Tech Stack:** Kotlin, Coroutines/Flow, Jetpack Compose Material 3, Coil, AndroidX Media3, NewPipeExtractor, JUnit, Compose UI tests, Gradle, Android SDK build tools, PowerShell, Git, GitHub CLI.

**Spec:** `docs/superpowers/specs/2026-08-30-hpre-1.0.11-startup-comments-release-design.md`

## Global Constraints

- Preserve application ID `com.hpre.app`, min SDK 26, target SDK 35, release minification, and resource shrinking.
- Set `versionCode = 12` and `versionName = "1.0.11"` only after feature tests pass.
- Keep Media3 buffers, startup-quality policy, source selection, retry, recovery, and network timeouts unchanged from 1.0.10.
- Add no dependency, telemetry service, cache framework, nested comments list, or per-comment card/surface.
- Comments remain read-only; do not add reply content, sorting, voting, posting, or author navigation.
- Use only `C:\Users\HUNG\.android\hpre-release.jks`, alias `hpre`, and credentials already held in user-level Gradle properties.
- Never print, copy, stage, or commit signing credentials, the keystore, `local.properties`, build directories, or `.superpowers` session files.
- Required signer SHA-256 is `40:D6:29:54:4B:6C:12:01:4A:D0:A0:3B:ED:C2:AF:FE:81:E6:DF:8E:F8:8F:69:3F:76:36:5A:6E:95:D4:9D:47`.
- A failed test, benchmark regression, signer mismatch, install-over failure, or data-preservation failure blocks public release.
- Execute in an isolated worktree on branch `perf/hpre-1.0.11-startup-comments`; create that worktree with the `using-git-worktrees` skill before Task 1.

private fun scheduleInitialComments(key: ContentKey, generation: Long) {
