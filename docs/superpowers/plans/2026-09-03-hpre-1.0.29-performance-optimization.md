# HPre 1.0.29 Performance Optimization & Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Triệt để tối ưu hóa thời gian mở video, tức thì hóa UI navigation sang Watch (<100ms) với thumbnail và khung player xuất hiện ngay lập tức, giữ thumbnail đến first frame, hợp nhất OkHttpClient connection pool, tăng cường telemetry cho first frame, cô lập pipeline phát video và phát hành bản HPre 1.0.29.

**Architecture:** Giữ vững nguyên lý lazy cold start, đưa mọi tác vụ phụ trợ (comments, related, heavy compose recomposition) ra khỏi critical path. Instant navigation truyền trực tiếp thumbnail và seed cache; trì hoãn spinner 150ms để loại bỏ visual flicker. Hợp nhất `OkHttpClient` giữa NewPipe extractor và player MediaSource để tận dụng socket/TLS pool.

**Tech Stack:** Kotlin, Jetpack Compose, Media3 ExoPlayer, NewPipeExtractor, OkHttp3, AndroidX Lifecycle / ViewModel, Gradle.

**Spec:** `docs/superpowers/specs/2026-09-03-hpre-1-0-29-performance-optimization-design.md`

## Global Constraints

- Android API minSdk 26, targetSdk 35.
- Baseline: HPre 1.0.28 (commit `56fc369`).
- `BUFFER_FOR_PLAYBACK_MS = 1000L` giữ nguyên theo chuẩn 1.0.28 (không hạ 500ms để tránh rebuffer).
- Không bật lại prefetch hàng loạt khi cuộn feed (`prefetch = no-op`).
- Không phá vỡ các unit test hiện có; giữ chuẩn release keystore.
