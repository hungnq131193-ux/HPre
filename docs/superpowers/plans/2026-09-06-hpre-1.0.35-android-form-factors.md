# HPre 1.0.35 Android Form Factors Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Ship one signed HPre 1.0.35 APK that installs and remains navigable on touch tablets, Android TV devices, and standard Android car displays.

**Architecture:** Keep the existing Compose navigation, Media3 playback, repositories, and release configuration. Add a small platform policy that derives touch versus remote input from PackageManager, expose it through a composition local, and use one adaptive clickable modifier for custom surfaces. Center non-Watch content inside a bounded wide-display host while leaving Watch/player surfaces full-width.

**Tech Stack:** Kotlin 2.1.20, Jetpack Compose Material 3, Android API 26+, Android Gradle Plugin 8.8.2, JUnit 4, PowerShell, Android SDK build-tools 35.0.0.

**Spec:** docs/superpowers/specs/2026-09-06-hpre-1.0.35-android-form-factors-design.md

## Global Constraints

- Preserve package com.hpre.app.
- Preserve versionName 1.0.35 and versionCode 36.
- Preserve the existing HPre release signing key and minified/resource-shrunk release build.
- Keep one APK and add no dependency, product flavor, ABI split, Android Auto template, or Automotive OS androidx.car.app screen.
- Preserve model/provider, local persistence, Media3 playback, PiP, background playback, and existing error paths.
- Treat touch as optional; Leanback and automotive features are optional, not required.
- Keep Watch/player content full-bleed; constrain only non-Watch navigation content to a maximum width of 1200 dp.
- Do not commit local.properties, app/video_cache, keystores, passwords, or generated APKs.
- Do not overwrite the existing root HPre-v1.0.35-release.apk; emit the candidate as dist/HPre-v1.0.35-android-standard-release.apk.

  - fromPackageManager reads PackageManager.FEATURE_LEANBACK, FEATURE_AUTOMOTIVE, and FEATURE_TOUCHSCREEN.
  - Define LocalHPreInputMode with TOUCH as its fallback.
  - Define ProvideHPreInputMode using CompositionLocalProvider.
