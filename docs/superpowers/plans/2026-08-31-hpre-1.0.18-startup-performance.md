# HPre 1.0.18 Startup Performance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Phát hành HPre 1.0.18 từ `v1.0.17` với controller/cache pre-warm, cache 128 MiB và progress UI cô lập, đồng thời giảm median `VIDEO_TAP` đến `PLAYER_PREPARE` ít nhất 15%.

**Architecture:** Giữ `VideoExtractionCoordinator`, `AppScopedPlayerControllerProvider` và `HPrePlaybackService` hiện có. Home idle khởi tạo factory/cache trên IO rồi tạo đúng một controller trên Main; việc bind service và tạo một service-owned `ExoPlayer` là tác dụng phụ đã được duyệt, nhưng không tạo media item, extraction, media-byte request hoặc `prepare()`. Shared `PlaybackState` chỉ nhận event cấu trúc; UI cần progress tự poll controller qua API suspend chạy trên main dispatcher.

**Tech Stack:** Kotlin, coroutines/StateFlow, Jetpack Compose, Android MessageQueue, AndroidX Media3, JUnit, Gradle 8.11.1.

**Spec:** `docs/superpowers/specs/2026-08-31-hpre-1.0.18-startup-performance-design.md`

## Global Constraints

- Base chính xác là tag `v1.0.17`, commit `3213caa`; nhánh là `perf/hpre-1.0.18-startup`.
- Không thêm dependency, player thứ hai, media prefetch, extraction khi idle hoặc subsystem mới.
- `HPrePlaybackService` tiếp tục là owner duy nhất của `ExoPlayer`.
- Pre-warm được phép bind service và tạo một `ExoPlayer`, nhưng không tạo media item, tải byte hoặc gọi `prepare()`.
- Cache stream bundle giữ TTL 20 giây, capacity 16 và identity-token refresh semantics hiện có.
- Media byte cache là 128 MiB; policy cache-key, delivery exclusion, fragment 2 MiB và fallback hiện có không đổi.
- Progress poll là 500 ms và không đi qua `WatchViewModel`, navigation hoặc Watch metadata content.
- Không tag, push release hoặc upload APK trước khi mọi release gate PASS.
